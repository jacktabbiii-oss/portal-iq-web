CUSTOM PLAYER HEADSHOTS
=======================

To add a custom headshot for any player:

1. Save the image in this folder
2. Name the file using the player's name (case-insensitive)

Supported formats: .jpg, .jpeg, .png, .webp

Naming Examples:
- "Travis Hunter.jpg"
- "travis hunter.png"
- "Shedeur Sanders.jpg"
- "arch manning.jpeg"

Tips:
- Square images work best (will be displayed as circles)
- Recommended size: 200x200 pixels or larger
- The system will check this folder FIRST before using On3 photos

The system searches for matches in this order:
1. Exact name match (e.g., "Travis Hunter.jpg")
2. Lowercase match (e.g., "travis hunter.jpg")
3. Name with underscores (e.g., "travis_hunter.jpg")
